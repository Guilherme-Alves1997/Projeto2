CELESTE

Este é um jogo indie publicado em 2018 que ainda é tratado como um dos melhores jogos de sempre, mas porquê? Este jogo foi criado pelo estudio Extremely OK Games, sendo um jogo 2D de plataforming com um estilo 8-bit. o conceito é básico, o ultimo update foi publicado para PC em 2021, então porque é que este jogo é tão popular?

O sucesso de celeste

O sucesso deste jogo deve-se a 3 razões principais:

  • qualidade
  • conteudo
  • comunidade

A qualidade do jogo é muito maior do que a de vários títulos AAA, desde a musica às mecânicas do jogo à arte, mesmo esta sendo maioritariamente 8-bit, é claro para todos que cada parte do jogo foi feita com muito cuidado para dar ao jogador a melhor experiência.

O conteudo do jogo utiliza as mecânicas que foram aprefeisoadas para criar niveis desafiantes e divertidos, com uma curva de dificuldade otimisada para desafiar o jogador de uma forma justa, que promove o sentimento satisfatório de melhoria à medida que o jogador progride no jogo.

A comunidade do jogo cresceu devido ao suporte dos criadores, que facilitaram o processo de entrar e participar na parte da comunidade dedicada a speedrunning. Eventualmente a counidade tornou-se numa das comunidades de modding mais ativas, com vários mods que adicionam mais conteudo ao jogo, algum várias vezes mais dificil do que qualquer desafio que o jogo base tenha para oferecer.
